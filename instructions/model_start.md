# Запуск cix-моделей, предназначенных для использования с ai_model_hub

## Этап 1: Загрузка моделей
Зайдите на сайт https://www.modelscope.cn/models/cix/ai_model_hub_25_Q3/summary, включите перевод на другой язык через браузер, затем зайдите в раздел с файлами. Ориентируясь по внутреннему файловому менеджеру, в папке models найдите нужную вам модель. В корне папки с моделью будет .cix файл, а в папке datasets - тестируемые данные. Скачайте нужные вам файлы, затем перенесите их в папку с моделью.

## Этап 2: Загрузка userspace
Поскольку было настроено виртуальное пространство, после каждого открытия консоли вам нужно выполнять следующую команду:
```bash
source /path/to/venv/.venv/bin/activate
```
## Этап 3: Тестирование модели
Перейдите в папку с моделью. Запустите:
```bash
python3 inference_npu.py
```
При необходимости вы можете указать дополнительные параметры.
